# 移動・切り替えの検証結果

2026-11-13。実測7試合、比較は4-2-3-1対4-4-2、同じ6シード（5000–5005）、GK除外・インプレー5Hz。原XMLは読み取りのみ。出典・抽出条件は [README.md](README.md)。コミット・pushなし。

原因と修正

- 保持交代の3秒定義は実測と一致。ボール位置の分布は異なるため、単純平均のライン差をそのまま補正しない。12×8の共通ボール位置セルについて、実測セル平均をsimの標本数で重み付けした比較を追加した（編成・移動方向・保持時間までは一致させていない）。
- 喪失後の遠い選手まで通常の帰陣・マークを優先し、攻撃時の幅が残っていた。近い選手の寄せと、残りのボール側への圧縮を分け、CBを前へ釣り出さないようにした。即時奪回は3人、帰陣は原則1人の寄せ。
- 奪取直後も旧裏抜け・通常攻撃のサポート探索が優先された。3秒間は密集した基準形を使い、速攻の前線だけ前進する。中盤はDMの前進上限と支援位置の後退を緩和した。
- 停止中も全員が高緊急度で移動し、整い次第再開していた。実測の停止標本比率44.6%、停止中平均1.12m/sに対し、旧simの停止時間は約14%。通常の寄せ・帰陣とスプリントを分け、位置微調整の許容幅を拡大し、停止中は歩行・ジョグで準備する。再開の最低準備時間をthrow/free/goalkick/corner=14/16/20/18秒に設定した。種類別の時間そのものは実測から同定した値ではなく、停止時間と再開準備の校正値。
