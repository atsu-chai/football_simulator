# 実トラッキングに基づく移動モデル

DFL / IDSSE 7試合（2022/23）の匿名集計を基準位置に使用する。出典は Bassek, Rein, Weber & Memmert (2025), Scientific Data 12:195, https://doi.org/10.1038/s41597-025-04505-y 。データは https://doi.org/10.6084/m9.figshare.28196177 、CC BY 4.0。座標の変換・間引き・集約を行った派生物であり、選手氏名と生軌跡は配布しない。

再現手順:

```sh
python3 scripts/data/extract_tracking.py --input /path/to/idsse
python3 scripts/data/test_extract_tracking.py
RESULT_JSON=docs/validation/tracking/comparison.json NODE_USE_SYSTEM_CA=0 node --import tsx scripts/compare-real.ts 6 --check
NODE_USE_SYSTEM_CA=0 node --import tsx scripts/audit.ts 30
NODE_USE_SYSTEM_CA=0 node --import tsx scripts/restarts.ts 6
NODE_USE_SYSTEM_CA=0 node --import tsx scripts/movement.ts 6 --check
OUT=docs/validation/tracking/balance UNIVERSAL=0 NODE_USE_SYSTEM_CA=0 sh scripts/balance-par.sh 100
NODE_USE_SYSTEM_CA=0 node --import tsx scripts/story.ts 30
NODE_USE_SYSTEM_CA=0 npm test
NODE_USE_SYSTEM_CA=0 npm run build
```

抽出では `ElementTree.iterparse` で各Frameを親から取り除き、5フレームごとの数値配列だけを保持する。データのSはkm/hからm/sへ、X/Yは中央原点から105×68mへ換算。GKの平均xで各半分の攻撃方向を推定し、180度回転して両チームを右攻めに揃える。保持はhome=1/guest=2、BallStatus=1だけをインプレーとする。11対11の92,675時点（チーム観測185,350）を使用。停止・保持不明89,907時点、11対11でない／欠損17,567時点を除外した。1試合は早期退場があり、ほとんどが対象外となる。サンプルは連続しており、独立観測92,675件を意味しない。

編成は開始時のDFLラベルを4-2-3-1、4-3-3、その他4バック、3バックの4系統にまとめる。5バックは3バック系統のデータと編成スロットを組み合わせる。既知のDFL役割ラベルを使用し、ラベルのない交代選手は同チーム・同ハーフの平均位置が近い既知選手で補う。交代後の実際の布陣変更は同定していない。

ボール位置12×8セル、保持・非保持・奪取後・喪失後（後者2つはインプレー保持交代後3秒）の平均形を抽出した。セルの欠損は全体平均へ、少ない系統データは全系統へ縮約する。周囲4セルを双線形補間し、前後位置は役割平均65%と編成スロット35%を使用する。左右と人数は編成スロットで保持する。GKの飛び出し・セーブ位置、個別のサポート・裏抜け・パス・ドリブル・シュート・マークの判断は既存層を使用する。

戦術は基準形への変形として表現する。同一ボール位置でのチーム間残差の10〜90百分位幅（各局面12チーム観測）を参考に、幅±18.4%、密集度による長さ±11.9%・幅±14.5%、ライン±5.66m、プレス開始位置の基準±8.27mとした。ラインは観測幅の2倍、プレスは1.5倍を使い、教材の両極が見えるようにしている。因果的な「設定を変えた効果」を7試合から推定したものではない。スロットの端と個別サポートで形が縮むため、幅1.15倍、保持時長さ0.92倍、基準線2〜3mの補正を試合比較で加えた。SBの上下・内側化、偽9番・インサイドWG、即時奪回・帰陣、速攻・保持の個別判断も重ねる。

速度95百分位5.35m/s、99百分位6.85m/s、99.9百分位8.25m/s。エンジンは通常走行上限を5.35、全速上限を8.0m/sにし、持ち場との距離で歩行〜走行を変える。加速度の絶対値90百分位2.05、99百分位4.55m/s²を参考に、通常2.05・緊急3.5m/s²に制限する。ボールとチーム重心の横方向1秒差分の相関は遅れ1.6秒で最大0.690。これは因果的な反応時間ではないため、半分の0.8秒を通常の目標位置の平滑化時定数に用いる。緊急の追走は0.15秒を維持する。旋回も速度ベクトルの加速度制約に従う。

停止込みの実測走行距離は追跡期間の速度を5400秒へ換算して10.23km／人。CB9.57、SB9.81、DM10.78、CM11.71、AM10.85、WG10.60、ST10.03、WB10.15km。インプレー速度だけを90分へ引き伸ばした13.64kmとは定義が違う。シミュレーションの停止込み距離は実移動距離×5400/1200で比較する。

`comparison.txt` と `comparison.json` は同一条件の実測対比と戦術差。実測・simともGKを除き、5Hzでインプレーだけを測る。ラインはx順の後方4人・中間3人・前方3人の平均。10/20m人数は保持者を含むフィールド選手。最寄り味方間隔は各選手の最寄り味方までの距離の平均。保持者圧力はボール3m以内の最寄り保持側選手に最も近い相手までの距離（GK含む）。実測は7試合、simは4-2-3-1対4-4-2・6シード。戦術対照は同じ6シードで変更側の実位置を測る。

`audit.txt` は3種類の組み合わせ×30シード=90試合。`restarts.txt` は別の6シード、`movement.json` は4-3-3対4-4-2・6シードであるため、各ログの平均は一致しない。`audit-before.txt` は変更前の3組×6シードの参考値で、試合数が異なる。キックオフでは配置を維持し、最初からキッカーをボールへ置くよう修正した。CKの特別配置は再開から3秒間だけ継続し、次の再開に残さない。

残る差:

- 保持時の中盤線は実測56.10mに対して51.25m。非保持のボール20m以内人数は3.97人に対して4.60人で、中央への寄りがやや多い。
- 切り替え直後は差が大きい。奪取後の守備線23.98m（実測34.10m）、喪失後の幅43.99m（37.24m）。奪取後の平均ボールxはsim34.66m・実測約43.08m（セル中心の概算）、喪失後は70.34m・約61.93mと保持交代が起きる場所も異なる。直前の攻撃形や戦術構成の影響も考えられ、無条件平均を同じにするための瞬間移動は入れていない。再開を保持交代と取り違える問題は `turnoverAt` で修正済み。
- 停止込み走行距離13.94kmは実測10.23kmより約36%多い。停止時間の比率と再開への移動が異なる。平均速度の一致だけで総走行距離まで再現したとは言えない。
- 5.5〜7m/s帯は6.6%（実測3.5%）と多い。加速・減速・旋回を抽出したが、役割別・局面別の全分布を再現する運動モデルではない。
- ミドル、ヘディング、ブロック、パス総数は監査目安から差が残る。シュート選択の構造は維持し、配置変更後の期待値係数だけ1.3から1.55へ校正した。
- `movement.ts --check` は平均速度±25%・総距離上限+40%等の粗い破綻検知であり、実測との一致を保証しない。総距離の差は上記のとおり残る。
- 再開位置はイベント時刻で別集計しているが、種類別の役割配置を再生するモデルは未実装。既存のCK等の配置規則を使用する。
- 学習に使った同じ7試合の統計との比較であり、別試合での汎化検証ではない。小標本、ラベル補完、開始布陣ラベル固定の制約がある。

レビューでは再開と保持交代の混同を修正し、戦術変形量の出所を明記・実装した。数値配列の列を名前付き型へ置き換える保守上の改善余地は残る。単位・左右反転・停止・保持交代は合成XML、疎な補間・編成差・偽9番・キックオフ・再開除外は単体テストで確認する。

最終の比較表は [results.md](results.md)、計測値は [comparison.json](comparison.json)、全ログはこのディレクトリに保存する。`solve-*.txt` は探索時点の候補であり、最終コードでの合否は `balance.txt` に記録する。ステージ3は探索した偽9番の解答へ変更、ステージ3・4・5の学習用弱点補正を調整した。ストーリーの弱点補正とは分離されている。

対策時の推計突破率がJFL→世界で順に下がるよう、J1の目標勝ち点を11から12に調整した。各章30シードを実行（章ごとに並列化し、変更したJ1だけ再実行）し、対策時は93.7%→82.7%→73.9%→69.7%→52.1%→35.7%となった。
