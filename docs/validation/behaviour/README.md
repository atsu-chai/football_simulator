残っている差

許容幅内でも実測と同一ではない。20m以内の人数は5.020→5.255/5.326で改善せず、実測4.131より多い。方向反転も17.1%→18.1/18.4%で、実測11.3%より多い。守備の最寄り味方p10は実測5.059mに対し4.213/4.020mで、例外的なプレス/受球/緊急帰陣には近接が残る。守備と中盤の間隔も実測9.396mに対し約8mで、やや詰まりすぎている。

攻撃側の役割別球相対RMSEはAM 15.005→13.239m、FB 11.490→11.746m、WG 8.081→10.586m。AMは改善しても大きく、FB/WGは悪化した。攻撃CM/STも少し悪化し、重心相対の全体RMSEは3.144→3.175mと改善していない。守備CM/WGの改善を、全役割の一致と解釈しない。攻撃は2つの学習形状と役割補正を併用しており、独立した走り・マークを完全に除いた実装ではない。位置の全分布を再現するには攻撃側の制御とボールの進行/反転の残差が課題として残る。全体誤差用の許容差を各役割へ流用して「役割別も合格」とは主張しない。

実測とsimの戦術/布陣/人数不足の露出は同一でなく、回帰と校正に使った7試合以外への一般化は未検証。全判定合格は、この固定した受入幅と2つのseed群における結果を指す。


計測の定義

旧18判定の定義と許容差は維持した。1Hz、GK除外、11対11、既知の保持、8秒間連続インプレー、同じ匿名選手の連続追跡だけを使う。帰陣と位置誤差は従来どおり位置順の4/3/3人。`lag0/1/2` は共通の実測4-4-2位置モデルとの差で、因果的な反応時間ではない。

新しい連動計測は人数が安定した9〜11人/チーム（GK込み）の窓も対象とする。7試合・14ハーフ、16,845窓。うち2,490窓は人数不足で、旧18判定の対象は14,355窓・13ハーフ。元データの2試合に退場があり、1つの後半には11対11のフレームがない。人数不足の座標を補完したり、別選手の軌跡を結合したりしていない。`coordinationSampling` がこの差を記録する。エンジンは常時11対11なので、新指標の全人数込み参照値と完全に同条件ではない。

- 役割の位置分布：攻撃/守備 × 球の縦3区画 × 横3レーン × CB、FB、DM/CM、AM、WG、ST。WBはFB、IWはWG、偽9番はSTへ集約。球からの相対x/yとチーム重心からの相対x/yの平均・標準偏差を保存する。左右反転は攻撃方向と一緒に180度回転する。
- ヒートマップ誤差：実測40標本以上・sim20標本以上の共通セルを、実測の露出数で重み付けする。位置RMSEは2次元距離、spread RMSEは4座標の標準偏差の誤差。セルの被覆率も独立して判定する。
- ユニット：CB/FB/WB、DM/CM、AM/WG/STの固定した役割群。守備群は4/5人全員を含む。守備群xのSD、群間の平均x差、各群で横に隣接する選手のy間隔を測る。これは布陣を推定した戦術ラインではない。人数別の隣接間隔も保存する。
- 連動：同じ役割群と球のx/y変位のPearson相関を1〜4秒で計測。群内の1秒速度相関は両方向のペアを加え、名簿の並び順に依存させない。速度が一定で相関を定義できない場合はnull。計測不能な相関を落として誤差を良く見せないよう、相関群ごとの被覆率も判定する。
- 重心の遅れ：球の1秒変位と重心の1秒変位の相関を0〜4秒で保存し、最大相関の遅れも記録。1Hzの粗い相関ラグであり、選手の反応時間を直接同定していない。
- 間隔と支援：最近接味方距離、対象窓の全外野選手の凸包面積、重心と同じ向きに動く選手の割合（双方0.5m/s超）。保持者は実測と共通の「球から3m以内の最寄り外野選手」。15m以内の味方数、同範囲の支援幅/深さ、FB/WGのタッチライン方向への広がりを測る。15mの人数は幾何学的な候補数で、パスコースが開いている保証はしない。

通常のカバー・支援が重なるときは、対称な補正で目標間隔を広げる（攻撃9m・守備10.5m、選手ごとの補正上限3.5m）。保持者・受け手・プレス・走り・緊急動作は例外にする。実位置の間隔は移動制御を含む分布で別に検証する。

窓は重なる。JSONの試合平均区間は試合を単位とする±2.45SEで、独立窓の有意差ではない。新指標の許容差は [coordination-limits.json](../../../src/data/coordination-limits.json) に保存した工学的な受入幅で、信頼区間ではない。検証結果を見て旧18指標の幅を緩めていない。

戦術差の評価

`compare-real.ts` の従来の戦術差6判定と移動/切替4判定は、無条件平均と元の閾値を維持した。加えて、ライン高・密集度・攻撃幅を両設定で観測された同じ球位置12×8セルで比較する。各群25標本以上の共通セルを両群の少ない方の標本数で重み付けし、追加判定も5m・3m・5mを要求する。共通セル12個以上、各群の総露出に対する重複標本量の割合40%以上を別に要求する。球の位置が違う試合展開を単純平均だけで比較しないための追加観測であり、従来の無条件判定の代替ではない。条件付けは戦術が試合展開へ及ぼす効果の一部も除くため、厳密な因果推定ではない。喪失直後の長さ/幅は従来の無条件判定を維持し、実測球位置セルとの差も診断値として併記する。

位置と動きの変更

攻撃の役割回帰だけを基準にして固定役割補正も除く案を、別コピーで12試合試走した。球相対の位置RMSEは6.40mだったが、10m/20m人数と重心を引いた8秒個人移動の3判定を外れた。この案を全置換には採用せず、攻撃側は既存の学習形状と役割回帰を併用している。

実測の役割・左右スロットごとに、球の位置、二次項、縦横の球速、奪取後経過時間を入力とするridge回帰を追加した。左右はハーフ全体の平均位置から固定し、瞬間的に左右が入れ替わってもスロットを交換しない。学習は11対11だけを対象とする。ファイル順の5試合で学習・2試合で検証し、配布モデルは7試合で再学習した。保持が継続する実測の将来位置を予測し、最終ラインは3秒、中盤・前線は4秒を目標にする。現在位置を追わせて移動制御の遅れを二重に加えることを避けるため、0/2/3/4秒の候補を行動比較で校正した。未来の球位置や未来の保持を実行時に入力してはいない。

[位置回帰の検証値](positioning-fit.json) は学習数・検証数・座標別RMSEを含む。検証標本がない役割/左右の組合せはnullで、誤差ゼロとは扱わない。モデル選択とエンジンの調整にはこのベンチマークも使ったため、これを完全に未知の試合での最終評価とは呼ばない。将来も同じ保持が続く窓を学習する選択の影響も残る。

守備はこの回帰を基準位置にし、攻撃は既存の実測グリッドと新しい役割回帰を併用した。既存グリッドを残したのは、7試合の平均から布陣ごとの人数配置や戦術の因果効果までは同定できないため。ライン高、プレス高、コンパクトさ、幅、SBの残留/オーバーラップ/内側化、偽9番、奪取・喪失直後の意図は明示した有界の変形として重ねる。WBの深さを固定式で上書きしていた処理も、学習位置からのオフセットへ変更した。深いビルドアップのCBは、左右約9.5mへ潰す固定式を外し、学習した左右位置を使う。高/低ラインはCBだけでなくSB/WBを含む後方ユニットの保持範囲へ反映し、正当に背後へ出たパスには追従する。

喪失後の帰陣で中盤/前線を一人ずつ球へ吸い寄せる補正を除き、共有の学習位置へ戻す。球より前に残った中盤には、切替中も通常守備と同じ帰陣条件を適用する。即時奪回の寄せは残す。寄せ・マーク・裏抜け・受球を決めたあと、全員を動かす前にユニットとして調整する。最寄りの残留スロットが空いた場所へ寄り、守備時のWBはバック5へ参加する。カバー量は横2.5m・縦2mまで。相手へのゾーンマークで中盤が基準位置から大きく前進する処理を制限した。担当を持たない選手も、プレス担当が追う保持者を重複対象にせず、他の相手の外側のパスコースをカバーする（CB最大6m、SB/WB最大12m）。SBが外側へ残ったまま相手から15〜20m離れる場面を減らす。球が急接近していないときは、後方ユニットが相手前線との余白を最大5m（低プレス2.5m）詰める。低いラインにはこの押し上げを適用しない。球速とライン速度の実測回帰を横方向にも拡張し、通常のスライドと攻撃の押し上げに使った。中盤・前線の帰陣も後方選手と同じく大きな目標誤差に応じて走る。喪失後3秒はSB/WGの内側への横帰陣にも帰陣ゲインを適用する。横帰陣だけで縦の後退応答は加えない。喪失直後のグリッド幅補正は1.50から1.10へ下げた。保持の支援は学習位置から4mの固定偏差へ変更し、毎tick現在位置の3m後ろへ退き続ける処理をやめた。速攻の前線は基準位置の10m先を出口にする。

[速度回帰](response-fit.json) は同じ5/2試合分割。速度上限・加速度制限・到着前の減速は維持した。球速の実測特徴は2秒変位、実行時は1秒時定数の速度平滑化を使うので完全に同じフィルターではない。ターゲットと特徴のキャッシュは1tick内だけ共有し、返す座標を複製する。キャッシュ追加前後の2試合・各12,000tickで、全選手の位置/速度/目標と球・得点が完全一致した。

位置回帰の予測時間、通常移動のゲイン、ユニットの間隔・幅の補正、得点・シュート判断の係数は、観測回帰とは区別した校正値。シュート判断とxGの係数は、近い守備者が増えた構成でもauditの得点・シュート範囲を満たすように再調整した。
