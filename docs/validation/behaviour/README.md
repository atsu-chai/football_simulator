原因と変更：

- 目標の後追いだけで帰陣する速度制御を、球の持続的な接近に応じた帰陣へ変更。開始時の試作（縦方向の先読みを含む）は24試合で変位中央値19.97m・取り残され3.11人。移動過多なので不採用。`src/engine/match.ts:148`、`tracking.ts:90`。
- 学習したSB/WBの深さを、守備処理がCBの高さへ潰していた。CB同士の深さを揃え、サイドの選手は自分の持ち場から相手へ出る。通常は1人が寄せ、残りは重複しない担当とカバー。`defending.ts:54`、`:95`、`:151`。
- 全ピッチで固定だった役割深度を、球の縦位置別の匿名実測へ変更。`tracking.ts:49`、`src/data/behaviour-response.json`。
- 受球後のコントロール、追走目標からの切替、余裕のある受球直後の逆向きパスのコストを追加。「保持」は前線が受けに戻り、「速攻」は前に出る。`ball.ts:387`、`onBall.ts:247`、`offBall.ts:35`。得点・シュート判断も再校正した。
- ステージ3はsolveで選んだ速いテンポ・SBのオーバーラップへ調整。J2の昇格目標10→11、J1は12→10。昇格条件だけの変更は記録した勝ち点分布から再計算し、試合結果は変えていない。

1Hz・両ハーフ・11対11。8秒間ずっとインプレーで保持が既知、同じ22人を追跡できる窓だけを使う。GKは除外し、ハーフ全体のGK平均位置から攻撃方向を正規化。交代・欠測・停止・ハーフの境界は跨がない。窓は重なるので、独立な標本として有意差を主張しない。JSONの `matchMean95` は試合単位平均の保守的な区間（±2.45SE）。

帰陣は4秒間の球の接近速度が2m/s超、同じ相手保持、球が自陣ゴールから15〜80mの時の後方4人／中間3人／前方3人の戻り速度。取り残されは自陣40m以内で守備中、FW・WG・GK以外で球より5m以上前にいる人数。球速2〜4・4〜6・6m/s超の層別と各ラインの位置誤差もJSONへ保存。全体平均に加え、分位点、役割別距離、8秒のブロック移動と重心を引いた個人移動も保存する。許容差は `scripts/behaviour.ts --check` に明記。同一分布や視覚的一致を保証する判定ではない。

実測由来は球の縦位置別の役割深度、速度・加速度の上位域、球速とライン速度の回帰。速度回帰の係数は5試合で学習し、残り2試合で確認した。位置形状は既存の全7試合モデルを使うため、完全に未知の試合での検証ではない。帰陣ゲイン、受球時間、マークの引き寄せ、シュート判断とxG補正は検証で校正した値で、回帰から直接得た係数ではない。
